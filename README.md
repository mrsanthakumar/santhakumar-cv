# Santhakumar R. — GitHub Pages CV Portfolio

A responsive, animated portfolio website built with plain HTML, CSS, and JavaScript. No build step or framework is required.

## Features

- Responsive layout for desktop, tablet, and mobile
- Animated profile monogram and project artwork
- Scroll reveal effects and reading progress bar
- Light/dark theme toggle
- Searchable list of 18 resume publications
- CV PDF link and contact links
- No home address displayed

## Publish with GitHub Pages

1. Create a **public** repository named `mrsanthakumar.github.io` (or `YOUR_USERNAME.github.io` if you change the GitHub username).
2. Upload all files and folders in this project to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the Pages deployment to finish. Open `https://mrsanthakumar.github.io/`.

If the repository uses a different name, the URL will normally be `https://YOUR_USERNAME.github.io/REPOSITORY_NAME/`. Relative asset paths in this project support that setup too.

## Customize

- Update email, phone, and GitHub URL in `index.html`.
- Replace `assets/Santhakumar_R_Resume.pdf` with your updated PDF while keeping the same filename.
- Check publication titles, venue details, and author order before relying on them as verified citations.
- The resume's original home address has intentionally not been copied into the website.
- The optional Google Fonts import needs internet access; system fallback fonts are used if unavailable.

## Privacy

Your email and phone number are public in this version, as requested. Do not add private information to a public repository. A public CV PDF may itself contain your home address; consider uploading a privacy-edited PDF before publishing. The PDF included here has the home-address line removed from page 1 before publication.
